# scoring-de-credito-inadimplencia
Modelo de scoring de crédito que estima a probabilidade de inadimplência em cobranças mensais, com engenharia de features 100% causal (sem vazamento temporal) e AUC de 0.94 na validação. Case técnico de ciência de dados em Python (pandas, scikit-learn).
